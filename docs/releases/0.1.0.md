# dsh-native-browser 0.1.0

The first stable release focuses on **macOS + Google Chrome**, controlling your existing browser tabs through DSH with semantic reads, verified actions, visible pointer feedback and explicit human handoff.

## Install

```sh
dsh plugin --profile web add dsh-native-browser@0.1.0 && dsh plugin --profile web exec dsh-native-browser install --browser=chrome
```

Replace both occurrences of `web` with your actual DSH profile. Requirements: Node.js ≥22.19, pnpm 11 and a working DSH installation. Declared DSH range: `>=0.1.5-rc.1 <0.3.0`; host-component checks cover `0.1.5-rc.1` and `0.2.1-rc.3`.

The installer stages the extension at a stable path, registers the Native Host, starts/checks the macOS background Broker and opens Chrome extensions plus Finder. In Chrome enable Developer mode and **Load unpacked** once; use **Command+Shift+G** in the directory picker to paste the printed path. Restart the DSH profile and authorize your chosen tab from the extension popup. Chrome Web Store distribution is not included.

## Capabilities

- Semantic page reads, scoped queries, long-page windows and compact observation output.
- Verified clicks, typing, scrolling, check/radio controls and bounded batches.
- Screenshots, model-assisted guarded visual clicks, file upload/download/chooser and JavaScript dialogs.
- Multiple tabs, agent-tab grouping and close, pointer feedback, Stop/handoff and foreground-conversation revocation.
- Collision-resistant `native_browser_*` names; optional legacy aliases skip names owned by other plugins.

## Upgrade from Alpha

Stop any old manually started Broker with Ctrl+C. Run the install line, replace the old extension loaded from npm/source with the printed stable directory, and restart DSH. Re-authorize tabs. Future upgrades reuse that directory and need an extension reload. Update old prompts to use `native_browser_*`.

The default approval mode remains per-action. `per-lease` and explicit `personal` configuration are described in the README. Installation does not silently change DSH approvals.

## Scope and evidence

See the release acceptance record and installation guide in the repository. Edge and complete Linux/Windows installation are experimental; unrestricted cross-origin frame control and automatic seamless recovery are not promised. Codex is a product-experience target, not a measured parity claim. Screenshot understanding depends on the configured model. Let a human handle irreversible business operations.
