# dsh-native-browser 0.1.4

修复 0.1.3 “设置 → 浏览器配置”内容空白的问题。

## 修复

DSH 启动后尚未选择或加载对话时，任务状态组件错误地把缺失的快照 ID 与未定义的当前对话 ID 判为匹配，随后读取空对象，导致整个设置内容渲染失败。

本版先检查快照存在且当前对话为有效字符串。没有对话时仍正常显示安装、连接诊断与扩展目录。缺失或格式不正确的任务状态响应被忽略，不阻断配置页。

## 更新与验收

1. 在实际使用的 DSH 应用中更新到 **0.1.4**。
2. 重载 DSH；如果设置内容仍为空，完全退出并重新打开 DSH。
3. 在未选择对话时打开 **设置 → 浏览器配置**，确认标题、配置按钮和连接检查仍显示；再切换对话检查页面。

这是 DSH 客户端界面修复，无需为此重新加载 Chrome 扩展。0.1.3 的任务收尾、指针与控制权策略继续有效。

Desktop 用户使用应用内插件管理。CLI/Web 用户可在自己的 profile 中安装固定版本，例如：

```sh
dsh plugin --profile web add dsh-native-browser@0.1.4
```

## 验证范围

真实 React/SlotCore 与隔离 Chrome 组件验收覆盖初始未选择对话（undefined）、null、选择和清空对话，以及三种异常任务状态响应；配置、连接诊断和任务卡片检查通过。607 项自动化测试与打包安装检查通过。

本机 DSH 0.1.3 安装已使用同等临时补丁；更新到本版本后使用正式包即可。没有把隔离组件验收宣称为完整 Desktop 外壳验收。

English: Fixes the blank browser setup page when Desktop has no selected conversation. Snapshot existence is checked before reading its value; malformed task status is ignored. Update the plugin to 0.1.4 and reload DSH. No Chrome extension reload is required for this UI fix.
