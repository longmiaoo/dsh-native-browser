# dsh-native-browser 0.1.6

让真实 Chrome 操作更连贯：虚拟鼠标在真实操作目标之间平滑移动，读取和导航也有明确状态反馈。

## 本版改动

- 虚拟鼠标按距离在 160–420 毫秒内移动，连续动作从当前显示位置转向最新目标；同一目标的按下和释放不会重复启动移动。
- 到达目标后播放点击、滚动和输入反馈。首次操作直接显示真实位置；没有点击、输入或滚动时，使用独立状态条呈现接管、读取、导航、截图和等待，不虚构鼠标位置。
- 动画只呈现已派发的操作，不增加真实输入，不等待动画结束再执行浏览器命令，也不代表业务操作已经成功。开启“减少动态效果”时直接定位。
- 导航时清除旧文档坐标，新文档恢复有效控制状态。清理扩展重载后残留的旧版指针，识别旧内容脚本并按需加载新显示组件。
- Stop、交还控制和租约到期后清除箭头与状态条；拦截迟到反馈，避免旧操作污染新接管状态，或旧 Stop 清除新状态条。
- 合并连续读取的状态通知，减少闪烁和通信；显示组件不注入 HTML 字符串，兼容启用 Trusted Types 的页面。
- 为多动作 Chrome MV3 测试提供 60 秒总预算，保留逐请求和产品动作的原有时限。本版不扩展浏览器权限或宿主支持范围。

## 更新：需要同步并重新加载 Chrome 扩展

本版修改了 Chrome 扩展代码，**只升级 DSH 插件不够**：

1. 在实际使用的 DSH 插件市场中更新 `dsh-native-browser` 到 **0.1.6**，按宿主提示重载。
2. 打开 **设置 → 浏览器配置 → 完成浏览器配置**，将新扩展同步到原有固定目录。
3. 在 `chrome://extensions` 找到 **DSH Native Browser**，点击扩展卡片上的“重新加载”。不需要删除再安装。
4. 返回 DSH，检查连接后开始新测试。若 DSH 仍加载旧客户端，完全退出后重新打开。

CLI/Web 用户也可以在实际使用的 profile 中执行，例如：

```sh
dsh plugin --profile web add dsh-native-browser@0.1.6
dsh plugin --profile web exec dsh-native-browser install --browser=chrome
```

随后仍需在 Chrome 扩展卡片上点“重新加载”。现有 Chrome 登录状态和用户标签页无需清理。

## 建议验收

让 DSH 使用 `native_browser_*` 工具在普通网页上点击输入框、输入文字，再点击另一个无外部副作用的按钮。箭头应在不同真实目标间连续移动；仅输入同一个框时不会随意游走。读取网页时应显示状态条；交还控制后箭头与状态条应消失。

## 验证与范围

- 617 项自动化测试、类型检查、元数据和依赖边界检查。
- 真实隔离 Chrome MV3：采样实际渲染的中间帧，覆盖连续移动、中途转向、按下/释放、减少动态效果、没有额外输入、导航清理、迟到消息、Stop 与到期。
- 打包安装后，经真实 DSH ToolRuntime、Native Messaging 和 Chrome 扩展执行填表到点击，验证多个移动帧及控制交还。使用隔离 Broker，不修改用户正在运行的服务。
- 全新安装、重复安装、alpha.10 升级及 Native Host 卸载/重装检查。
- 正式支持范围仍是 **macOS + Chrome**；Chrome Web Store 尚未上架。以上不等同于完整 Desktop 外壳与模型自主日常任务的全面验收。

English: Smooth virtual cursor motion between dispatched targets, separate activity feedback for read/navigation/capture/wait, reduced-motion support, and fenced cleanup across Stop, navigation and regrant. After updating to 0.1.6, rerun DSH browser setup and reload the existing Chrome extension. Upgrading the npm plugin alone does not hot-reload Chrome code.
