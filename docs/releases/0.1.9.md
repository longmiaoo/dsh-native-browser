# dsh-native-browser 0.1.9

让浏览器长任务保持连续：personal 模式自动维护有效控制权，解决固定两分钟到期导致的中断；同步刷新虚拟鼠标和活动条。更新配置页，连接进度和回到聊天的入口更清楚。

## 改进

- 自动续期沿用当前对话、标签页和控制 token，不重新申请控制、不重复附加 debugger，也不重放输入。Stop、交接、切换对话、断线和轮次结束会停止维护；十分钟没有新的浏览器工具活动也会停止。
- Broker 和扩展都验证当前权限、原期限和本地控制状态。迟到的续期确认不能恢复已撤销的控制。续期能力按需协商，旧组件保留原有固定期限；restricted 模式不开放自动续期。
- 任务状态保留最近动作的精简回执。结果未知或条件未确认时提示核验；未派发的目标失效、控制权丢失和连接问题提供对应提示。读取成功不代表之前的输入已经成功，不自动重放输入。
- 配置页增加清晰的连接进度、就绪状态和“回到聊天”入口，支持深浅主题与窄窗口，保留原有配置、权限和诊断功能。

## 升级步骤

1. 在当前 DSH 的插件管理中更新到 **0.1.9**，按提示重载 DSH。
2. 打开左侧 **浏览器**，点击 **完成浏览器配置**，同步新版 Broker 和扩展文件。
3. 到 Chrome 扩展管理页，在 DSH Native Browser 卡片点击 **重新加载**。
4. 回到配置页检查连接，再开始聊天。

本版需要新版后台和 Chrome 扩展；仅重载 DSH 不能启用续期。已经加载过固定目录的用户无需删除扩展、重新找目录或重新安装 Chrome。

CLI/Web 高级用户可更新自己实际使用的 Profile，例如：

```sh
dsh plugin --profile web add dsh-native-browser@0.1.9
dsh plugin --profile web exec dsh-native-browser install --browser=chrome
```

Desktop 用户使用应用内配置，不必寻找 Profile 名称。Chrome 商店版仍未上架，首次安装仍需确认加载已解压的扩展。

## 验证与范围

642 项自动化测试通过，覆盖续期、空闲预算、Stop 竞争、跨连接/会话隔离、新旧组件协商、未知结果和目标失效提示。真实隔离 Chrome MV3、Native Messaging 与 DSH ToolRuntime 回归通过。

从打包文件安装到全新目录，使用默认 personal 模式，在不轮询浏览器工具的情况下静置超过原两分钟期限后，仍用同一控制权和目标 ref 成功输入；指针、活动条及交接清理均正常。配置页另通过真实 React/SlotCore 的交互验收。

支持范围仍为 **macOS + Chrome**。这些是确定性工具调用和隔离测试，不代表大模型任意任务成功率、数小时稳定性或已达到 Codex 的性能。[实现与验收记录](../browser-continuity.zh-CN.md)列出了具体边界。

English: Personal-mode lease keepalive prevents fixed two-minute interruptions during active browser work. Renewal preserves the existing owner/token and refreshes cursor/activity deadlines; Stop, handoff, conversation switches and lifecycle boundaries still revoke control. Adds actionable outcome guidance and a refreshed responsive setup page. Update the plugin, rerun Set up Chrome, then reload the Chrome extension.
