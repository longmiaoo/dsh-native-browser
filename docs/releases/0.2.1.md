# dsh-native-browser 0.2.1

更顺滑的默认行为：不再拦截任何导航地址，租约默认 5 分钟，下载不再确认，上传默认允许用户主目录，后台标签页上的输入会立刻给出明确错误。

## 行为变化（请注意）

- **导航不再拦截。** 模型现在可以打开或导航到任意 HTTP(S) 地址，包括 localhost 和内网地址。0.2.0 中对本机、内网地址的拦截已移除，因此插件不再缓解“网页引导模型访问本机或内网服务（含云元数据地址）”的风险。
- **租约默认 5 分钟**（原 2 分钟）。个人模式仍会自动续期，首次续期约在 2.5 分钟时。**新扩展和新 Broker 必须一起使用**：旧扩展会拒绝超过 5 分钟的期限。
- **下载不再确认。** 上传和选择文件仍然每次确认，且不允许出现在 `batch` 中。
- **上传默认目录改为用户主目录。** 隐藏文件、隐藏目录、`~/Library` 以及 Broker 运行目录仍然禁止；`--upload-root` 会替换默认目录。

## 改进

- 在后台标签页上执行 click、fill、append、press、check、wheel、visual-click 时，立即返回 `NOT_ACTIONABLE` 并提示先调用 `native_browser_activate`，不再返回“已发送”后超时。不会自动切换标签页，避免抢走你的焦点。

## 升级步骤

1. 在 DSH 插件管理中更新到 **0.2.1**，按提示重载 DSH。
2. 打开左侧 **浏览器**，点击 **完成浏览器配置**，同步新版 Broker 和扩展文件。
3. 到 Chrome 扩展管理页，在 DSH Native Browser 卡片点击 **重新加载**。
4. 重启后台（Broker），回到配置页检查连接。

English: Smoother defaults. Navigation and open are no longer restricted (including localhost and private addresses), the default lease is five minutes, downloads no longer ask, uploads default to the home folder (each upload still asks; hidden files and ~/Library stay excluded), and input on a background tab now fails immediately with NOT_ACTIONABLE. Reload the extension and restart the Broker together.
