# dsh-native-browser 0.2.2

修复版本：带有隐藏跨域 iframe 的页面（例如小红书）现在可以正常截图。

## 修复

- 页面里有 `display:none`、已分离或没有渲染面积的跨域 iframe 时，`native_browser_screenshot` 不再整体返回 `POLICY_DENIED`。只有当 `DOM.getContentQuads` 明确返回空列表（该 frame 没有渲染面积、没有像素需要打码）时才跳过；其他几何测量失败、仍有渲染内容的 frame 依旧拒绝截图。感谢 @wiaoo 的贡献（#1）。

## 升级步骤

1. 在 DSH 插件管理中更新到 **0.2.2**，按提示重载 DSH。
2. 打开左侧 **浏览器**，点击 **完成浏览器配置**，同步新版 Broker 和扩展文件。
3. 到 Chrome 扩展管理页，在 DSH Native Browser 卡片点击 **重新加载**。

English: Fix: screenshots no longer fail on pages that contain a hidden or unrendered cross-origin iframe; a frame is skipped only when Chrome proves it has no rendered area, otherwise the capture is still denied. Thanks to @wiaoo (#1).
