# dsh-native-browser 0.2.3

0.2.2 的发布被 CI 拦下后补齐的稳定版本。包含隐藏跨域 iframe 截图修复，以及滚动触发页面变更时的一个输入竞态修复。

## 修复

- 带有 `display:none`、已分离或没有渲染面积的跨域 iframe 的页面（例如小红书）现在可以正常截图；只有 Chrome 明确证明该 frame 没有渲染面积时才跳过，仍会渲染的 frame 继续拒绝截图。感谢 @wiaoo 的贡献（#1）。
- 修复 `check` 的一个竞态：目标在滚动后才于下一帧触发页面处理，修改单选框的 `form`、`name` 或 `value` 时，旧实现可能先点击再报告 `STALE_TARGET`。现在滚动后先等待一个渲染帧，再执行最终身份与绑定检查；会在输入前返回 `STALE_TARGET`。

## 发布说明

- `v0.2.2` 标签曾经创建，但该提交的 CI 未通过，因此 npm 上没有 0.2.2 包。请使用 `0.2.3`，标签 `v0.2.2` 不会被覆盖。

## 升级步骤

1. 在 DSH 插件管理中更新到 **0.2.3**，按提示重载 DSH。
2. 打开左侧 **浏览器**，点击 **完成浏览器配置**，同步新版 Broker 和扩展文件。
3. 到 Chrome 扩展管理页，在 DSH Native Browser 卡片点击 **重新加载**。

English: Stable follow-up after the 0.2.2 publish gate failed. Includes the hidden cross-origin iframe screenshot fix and a scroll-triggered radio race fix that now waits one rendered frame before final identity checks. No 0.2.2 package was published; use 0.2.3.
