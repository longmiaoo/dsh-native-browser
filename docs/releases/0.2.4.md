# dsh-native-browser 0.2.4

DSH「浏览器」配置页现在可以区分 Chrome 已连接和组件已更新。即使旧扩展仍在线，页面也会显示「已连接 · 需更新」并给出下一步。

- 「组件版本」分别显示 DSH 插件、正在运行的 Broker、Chrome 实际加载的扩展，以及磁盘上的扩展文件。
- 同步组件后，页面会根据连接状态提示加载或重载扩展。已连通的旧组件如果尚未提供版本信息，会显示「未确认」。
- 连接检查只读取状态。同步组件由用户点击触发，Chrome 扩展在扩展管理页手动加载或重载。

## 升级

1. 在 DSH 中更新插件到 **0.2.4**，按提示重载 DSH。
2. 打开左侧 **浏览器**，点击 **同步浏览器组件**（首次使用显示 **完成浏览器配置**）。
3. 在 Chrome 扩展管理页找到 **DSH Native Browser**，点击 **重新加载**。首次使用请按向导选择扩展目录。
4. 返回 DSH 点击 **检查连接**，确认 Chrome 已就绪。

## 验证

覆盖配置页的首次连接、旧组件、扩展重载以及恢复就绪。从已发布的 0.2.3 在隔离的 Chrome Profile 中同步组件并点击实际的扩展重载按钮。打包后的插件也通过当前 DSH Desktop 自带组件和真实 Chrome 的工具链验收，包括中文填表、截图和交还控制。正式支持范围为 macOS + Chrome。

English: The setup panel now distinguishes an active connection from an up-to-date installation. It reports the plugin, running Broker, loaded Chrome extension and staged files separately, and guides you through sync and reload.
